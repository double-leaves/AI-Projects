# Hero 组件优化说明

## 优化内容

### 1. ✅ 组件尺寸缩小约 50%

#### 头像大小
- **之前**: 160px × 160px (移动端), 192px × 192px (平板/桌面)
- **现在**: 96px × 96px (移动端), 112px × 112px (平板/桌面)
- **Emoji 大小**: 从 `text-6xl` 改为 `text-4xl`

#### 标题尺寸
- **之前**: `text-5xl md:text-7xl lg:text-8xl` (48px / 72px / 96px)
- **现在**: `text-3xl md:text-4xl lg:text-5xl` (30px / 36px / 48px)

#### 副标题尺寸
- **之前**: `text-xl md:text-2xl lg:text-3xl` (20px / 24px / 30px)
- **现在**: `text-base md:text-lg lg:text-xl` (16px / 18px / 20px)

#### 简介文字
- **之前**: `text-base md:text-lg` (16px / 18px)
- **现在**: `text-sm md:text-base` (14px / 16px)

#### 按钮尺寸
- **之前**: `px-8 py-3` (padding 32px × 12px)
- **现在**: `px-6 py-2.5` (padding 24px × 10px)
- **文字**: 添加 `text-sm` (14px)

#### 间距调整
- **容器最大宽度**: 从 `max-w-4xl` 改为 `max-w-3xl`
- **头像下边距**: 从 `mb-8` 改为 `mb-4` (从 32px 到 16px)
- **标题下边距**: 从 `mb-6` 改为 `mb-3` (从 24px 到 12px)
- **副标题下边距**: 从 `mb-8` 改为 `mb-4` (从 32px 到 16px)
- **简介下边距**: 从 `mb-12` 改为 `mb-6` (从 48px 到 24px)
- **按钮间距**: 从 `gap-4` 改为 `gap-3` (从 16px 到 12px)
- **简介最大宽度**: 从 `max-w-2xl` 改为 `max-w-xl`

### 2. ✅ 删除向下滚动图标

完全移除了底部的"向下滚动"提示和动画箭头，使界面更简洁。

### 3. ✅ 避免头像被导航栏遮挡

在 section 元素添加 `pt-20` (padding-top: 5rem)，确保内容不会被固定的导航栏遮挡。

## 如何进一步调整

如果觉得还需要微调，可以修改以下值：

### 让组件更小
```tsx
// 头像
w-20 h-20 md:w-24 md:h-24  // 更小的头像

// 标题
text-2xl md:text-3xl lg:text-4xl  // 更小的标题

// 间距
mb-2, mb-3  // 减少边距
```

### 让组件稍大
```tsx
// 头像
w-28 h-28 md:w-32 md:h-32  // 稍大的头像

// 标题
text-4xl md:text-5xl lg:text-6xl  // 稍大的标题

// 间距
mb-6, mb-8  // 增加边距
```

### 调整顶部间距
```tsx
// 如果导航栏很高
pt-24 或 pt-28

// 如果导航栏很矮
pt-16
```
