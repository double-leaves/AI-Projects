## 交互效果

### 按钮悬停
```
查看作品按钮:
  默认    → [查看作品 →]
  悬停    → [查看作品  →]  (放大 105%, 阴影效果, 箭头右移)

联系我按钮:
  默认    → ⬜ 联系我  (透明背景, 紫色边框)
  悬停    → ⬜ 联系我  (浅紫色背景, 亮紫色边框)
```

### 头像边框
```
持续旋转动画 (8 秒完成一圈)

  0s      2s      4s      6s      8s
  🟣━━━━━━━━━━━━━━━━━━━━━━━━🟣
  ↻                           ↺
```

### 滚动提示
```
上下浮动动画 (2 秒循环)

  0.0s  向下滚动 ↓
  1.0s  向下滚动 ↓  (下移 10px)
  2.0s  向下滚动 ↓  (回到原位)
```

## CSS 实现要点

### 文字渐变
```css
background: linear-gradient(to right, purple-400, pink-400, purple-400);
-webkit-background-clip: text;
-webkit-text-fill-color: transparent;
```

### 头像外圈
```css
/* 外层旋转 div */
position: absolute;
background: linear-gradient(to right, purple-500, pink-500, purple-500);
animation: rotate 8s linear infinite;

/* 内层头像 */
position: relative;
background: #0a0a0a;
```

### 背景装饰
```css
/* 左上紫色光圈 */
position: absolute;
top: 25%;
left: -8rem;
width: 16rem;
height: 16rem;
background: purple-500 with 10% opacity;
filter: blur(64px);

/* 右下粉色光圈 */
position: absolute;
bottom: 25%;
right: -8rem;
width: 24rem;
height: 24rem;
background: pink-500 with 10% opacity;
filter: blur(64px);
```

## 可访问性

### 语义化 HTML
```html
<section>        <!-- 语义化区块 -->
  <h1>           <!-- 主标题 -->
  <p>            <!-- 段落 -->
  <a>            <!-- 链接 -->
```

### 键盘导航
- Tab 键可依次访问两个按钮
- 回车键可激活按钮

### 屏幕阅读器
- 头像有 `alt` 属性描述
- 链接有明确的文字说明

## 开发建议

### 1. 测试不同屏幕尺寸
```bash
# 使用浏览器开发工具测试以下设备
- iPhone SE (375px)
- iPhone 12 Pro (390px)
- iPad (768px)
- iPad Pro (1024px)
- Desktop (1440px)
- Desktop 4K (2560px)
```

### 2. 性能监控
```javascript
// 监控动画性能
performance.mark('hero-animation-start');
// ... 动画代码
performance.mark('hero-animation-end');
performance.measure('hero-animation', 'hero-animation-start', 'hero-animation-end');
```

### 3. 暗色模式
当前已是暗色主题，如需添加亮色模式：
```tsx
className="bg-[#0a0a0a] dark:bg-white"
className="text-white dark:text-black"
```
